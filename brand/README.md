# Логотип «Здай ПДР»

**Ідея:** галочка «здав» — це дорога з розміткою. Один знак: результат (склав іспит) і шлях до нього (водіння).

## Файли

| Файл | Де використовувати |
|---|---|
| `zdaipdr-horizontal.svg` | основний логотип: знак + назва в рядок, світлий фон |
| `zdaipdr-horizontal-reversed.svg` | те саме на темному фоні |
| `zdaipdr-stacked.svg`, `-stacked-reversed.svg` | у стовпчик (аватар, квадратні місця) |
| `zdaipdr-symbol.svg` | лише знак, кольоровий, світлий фон |
| `zdaipdr-symbol-reversed.svg` | знак на темному фоні (розмітка прорізана, видно фон) |
| `zdaipdr-symbol-black.svg`, `-white.svg` | один колір: друк, штамп, гравіювання |
| `zdaipdr-symbol-small.svg` | менше 32 px: без розмітки |
| `zdaipdr-favicon.svg` | вкладка браузера (`web/icon.svg`) |
| `zdaipdr-icon-any.svg` / `zdaipdr-app-icon.svg` / `zdaipdr-apple-touch.svg` | іконки застосунку: звичайна / maskable (знак у безпечній зоні 80 %) / iOS |
| `zdaipdr-wordmark.svg` | лише назва |

Усе генерує `build_kit.py` з однієї геометрії — змінюйте його, а не SVG вручну.

## Кольори

| | HEX | RGB |
|---|---|---|
| Асфальт (знак, текст) | `#1A1D23` | 26 29 35 |
| Розмітка (акцент, плитка іконки) | `#FFC21A` | 255 194 26 |
| Білий | `#FFFFFF` | 255 255 255 |

Жовтий на асфальті — контраст ≈ 11:1. Жовтий текст на білому не використовуйте (контраст ≈ 1,7:1).

## Правила

- **Вільне поле** навколо логотипа — не менше за ширину дороги в знаку (≈ ¼ висоти знака).
- **Мінімальний розмір:** знак з розміткою — від 32 px; менше — `symbol-small`. Логотип у рядок — від 120 px завширшки.
- **Фони:** білий, світло-сірий, асфальт, жовтий (на жовтому — знак без жовтої розмітки, як в іконці).
- **Не можна:** розтягувати, повертати, міняти кольори розмітки, додавати тіні й градієнти, ставити на строкаті фото,
  набирати назву іншим шрифтом.
